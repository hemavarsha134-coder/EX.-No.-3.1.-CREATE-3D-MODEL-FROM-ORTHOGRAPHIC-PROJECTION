# EX. No.3.1. CREATE 3D MODEL FROM ORTHOGRAPHIC PROJECTION


## AIM:
To create a 3D model from given orthographic projection.

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
1. Create a New Sketch: Open Autodesk Fusion 360, select the XY plane, click on Create Sketch, and use the Line and Rectangle tools to draw the basic fork-shaped profile according to the given engineering drawing.

2. Draw the Main Profile: Use the Rectangle tool to create the main body with an overall length of 52 mm and width of 32 mm, then draw the central rectangular slot to form the two parallel arms.

3. Apply Dimensions: Select the Sketch Dimension (D) tool and specify the required dimensions, including 52 mm overall length, 32 mm width, 18 mm slot opening, and 11 mm arm thickness to maintain accurate proportions.

4. Create Circular Profiles: Select the Circle tool and draw the required circular holes with a diameter of 16 mm (Ø16) at the rounded ends of both arms, ensuring that their centres are properly aligned.

5. Apply Radius: Use the Sketch Fillet tool to create the rounded outer ends of the two arms, applying an R16 mm radius based on the 32 mm overall width to obtain a smooth semicircular profile.

6. Trim Unwanted Lines: Select the Trim tool (T) and remove unnecessary overlapping lines, extra circular portions, and unwanted sketch segments to obtain a clean fork-shaped profile with properly aligned holes.

7. Extrude the Main Body: Finish the sketch, select the required closed profile, choose the Extrude command (E), and provide the required 20 mm thickness according to the drawing to create the three-dimensional body.

8. Create the Cylindrical Extension: Select the Circle tool on the required face, draw a circular profile with an 18 mm diameter, and use the Extrude command to create the cylindrical extension with a length of 32 mm.

9. Create the Required Cutouts: Use the Extrude Cut operation to create the central opening and circular holes through the arms, maintaining the specified 18 mm slot dimension and 16 mm hole diameter.

10. Final Inspection and Save: Inspect the completed 3D model using the Isometric view, verify the dimensions, diameter, radius, arm thickness, and cylindrical extension according to the engineering drawing, and save the final design.
